# HostsLauncher & HostsManager

Комплексный инструмент для Windows для удобной работы с системным файлом `hosts`:
1. **Мгновенный запуск из панели задач** в любом выбранном редакторе (Блокнот с правами администратора, Notepad++, VS Code).
2. **Графический генератор ярлыков** с привязкой к динамической системной иконке Windows.
3. **Автообновление и синхронизация подписок** (GeoHide и др.) с изоляцией блоков и защитой личных записей.
4. **Тихое фоновое автообновление** через Планировщик задач Windows.

---

## 🏗️ Архитектура проекта

Для максимальной чистоты и удобства система разделена на два специализированных исполняемых файла:

```text
HostsLauncher/
├── src/
│   ├── Program.cs             # Исходный код HostsLauncher (быстрый лаунчер для панели задач)
│   └── HostsManager.cs        # Исходный код HostsManager (GUI, генератор ярлыков, синхронизация)
├── dist-win-unpacked/
│   ├── HostsLauncher.exe      # Легковесный раннер (0 мс, запуск редактора из панели задач)
│   ├── HostsManager.exe       # Графическая панель управления
│   └── config.json            # Портативная конфигурация (без реестра Windows)
├── build.bat                  # Скрипт сборки через штатный Windows-компилятор (csc.exe)
├── create_shortcuts.bat       # Быстрое создание ярлыка с системной иконкой
├── .gitignore
└── README.md
```

### 1. `HostsLauncher.exe` — Быстрый раннер для панели задач
* **Назначение:** Закрепляется на панели задач или рабочем столе.
* **Скорость:** Запускается за 0.01 сек без отображения окон управления.
* **Иконка:** Ссылается напрямую на системную библиотеку `%SystemRoot%\System32\shell32.dll,0` (значок файла без расширения). При обновлении дизайна Windows иконка автоматически обновляется.
* **Поддержка аргументов:**
  * *(без параметров)* — стандартный системный диалог Windows «Открыть с помощью...»
  * `/npp` — сразу в Notepad++
  * `/code` или `/vscode` — сразу в Visual Studio Code
  * `/notepad` — в системном Блокноте от имени администратора (сохранение через Ctrl+S без ошибок)
  * `/subl` — в Sublime Text
  * `"C:\Путь\Редактор.exe"` — в любой указанной программе
  * `/admin` — принудительный запуск выбранного редактора с повышенными правами

### 2. `HostsManager.exe` — Панель управления и синхронизация (GUI)
* **Вкладка 1: 🚀 Создать ярлык**
  * Выбор редактора (Блокнот, Notepad++, VS Code или выбор любого `.exe`).
  * Выбор системной иконки.
  * Создание ярлыка на Рабочем столе в 1 клик.
* **Вкладка 2: 🌐 Подписки hosts (GeoHide)**
  * Встроенная поддержка сервиса [GeoHide](https://dns.geohide.ru:8443/) с выбором одного региона (`Россия (RU)`, `Европа (EU)` или `США (US)`). Регионы являются взаимоисключающими, так как содержат один список доменов с разными региональными IP.
  * Возможность добавления любых сторонних независимых URL-списков правил (AdBlock, корпоративные блокировки и т.д.).
  * Кнопка «Синхронизировать hosts сейчас» — скачивание, проверка хэша SHA256 и автоматический сброс DNS-кэша Windows (`DnsFlushResolverCache`).
* **Вкладка 3: ⏱️ Автообновление (Планировщик)**
  * Включение тихой проверки обновлений (каждые 6/12 часов, раз в день или при входе в Windows).
  * Настройка стандартного Планировщика задач Windows (`schtasks.exe`).
  * В фоновом режиме запускается `HostsManager.exe /update-silent`: если хэш файла на сервере не изменился, диск не перезаписывается.

## 🔒 Безопасность и хранение данных

1. **Без реестра Windows (100% Portable):**  
   Все настройки хранятся в файле `config.json` рядом с исполняемыми файлами. Никаких записей в реестр не вносится.
2. **Изоляция в файле hosts:**  
   Правила от внешних провайдеров вставляются в `%SystemRoot%\System32\drivers\etc\hosts` **строго внутри маркированных блоков**:
   ```text
   # === BEGIN HOSTS-MANAGER MANAGED BLOCK [GeoHide (RU)] ===
   # Source: https://geohide.ru/hosts
   # Updated: 2026-09-30 02:40:00
   ... правила провайдера ...
   # === END HOSTS-MANAGER MANAGED BLOCK [GeoHide (RU)] ===
   ```
   **Ваши личные записи до и после этого блока никогда не затираются.** При отключении провайдера блок чисто удаляется. Перед каждой перезаписью создается резервная копия `hosts.bak`.

## 🛠️ Сборка из исходников

Для сборки проекта не требуются сторонние SDK или Visual Studio. Используется штатный компилятор C# (`csc.exe`), входящий в состав .NET Framework 4.x в любой современной Windows:

```cmd
build.bat
```

Скрипт скомпилирует оба исполняемых файла в каталог `/dist-win-unpacked/`.
