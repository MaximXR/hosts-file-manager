# HostsLauncher — Быстрый запуск и редактирование hosts файла

Легковесная утилита для быстрого открытия системного файла `hosts` (`%SystemRoot%\System32\drivers\etc\hosts`) в любом текстовом редакторе.

---

## 📂 Структура репозитория

```text
HostsLauncher/
├── src/
│   └── Program.cs             # Исходный код C# (чистое GUI-приложение без консоли)
├── dist-win-unpacked/
│   └── HostsLauncher.exe      # Скомпилированный бинарник
├── build.bat                  # Скрипт сборки через встроенный Windows-компилятор (csc.exe)
├── create_shortcuts.bat       # Создание ярлыков на Рабочем столе с системной иконкой
└── README.md                  # Документация проекта
```

---

## 🛠️ Сборка (Компилятор)

Для сборки проекта не требуется устанавливать сторонние SDK или Visual Studio. Используется штатный компилятор C# (`csc.exe`), поставляемый вместе с Windows (.NET Framework 4.x).

Чтобы собрать проект, запустите:
```cmd
build.bat
```
Скрипт автоматически найдет `csc.exe` в системе и соберет исполняемый файл в папку `/dist-win-unpacked/HostsLauncher.exe`.

---

## 🚀 Закрепление на панели задач

1. Запустите `create_shortcuts.bat` (или создайте ярлык для `dist-win-unpacked/HostsLauncher.exe`).
2. Нажмите правой кнопкой мыши по созданному ярлыку на Рабочем столе.
3. Выберите пункт **«Закрепить на панели задач»**.
4. Готово! Файл `hosts` открывается в один клик.

> **Иконка:** Ярлык явно ссылается на системную динамическую иконку Windows (`%SystemRoot%\System32\shell32.dll,0` — файл без расширения). При любых будущих обновлениях дизайна иконок Windows ярлык автоматически подтянет актуальный системный вид.

## ⚙️ Параметры запуска

В свойствах ярлыка в поле **«Объект»** (Target) можно передавать аргументы:

| Параметр | Поведение |
| :--- | :--- |
| *(без параметров)* | Открывает стандартное системное окно Windows **«Открыть с помощью...»** |
| `/npp` | Открывает сразу в **Notepad++** (права администратора Notepad++ запросит сам при сохранении) |
| `/code` или `/vscode` | Открывает сразу в **Visual Studio Code** |
| `/notepad` | Открывает сразу в **Блокноте** с правами администратора |
| `/subl` | Открывает в **Sublime Text** |
| `"C:\Путь\К\Редактору.exe"` | Открывает в **любом указанном редакторе** |
| `/admin` | Принудительный запуск выбранного редактора **от имени администратора** (например: `HostsLauncher.exe /code /admin`) |
